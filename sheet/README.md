# 시트 연결 (v2: 대표별 탭)

- 저장하면 시트에 **이기헌**, **백효인** 탭이 각각 생기고, 그 대표의 기록만 그 탭에 쌓인다.
- 열: 저장시각 / 가설·질문 / 내용 / 입력값·근거·의견 / 판정 / 그때의 결론 / raw
- 불러오기는 두 탭을 합쳐 가져와 페이지에서 대표별로 복원한다.

## 코드 교체 방법 (1분)
1. 시트 → 확장 프로그램 → Apps Script
2. 기존 코드 전부 지우고 `Code.gs` 붙여넣기 → 저장
3. 배포 → **배포 관리** → 연필 → 버전 **새 버전** → 액세스 **모든 사용자** → 배포
4. 웹 앱 URL은 그대로라 페이지는 안 고쳐도 됨

예전 '기록' 탭은 테스트 데이터라 지워도 된다.
