# 시트 연결 (v3: 대표별 탭 + 사전 설문)

- 저장하면 시트에 **이기헌**, **백효인** 탭이 각각 생기고, 그 대표의 기록만 그 탭에 쌓인다.
- 열: 저장시각 / 가설·질문 / 내용 / 입력값·근거·의견 / 판정 / 그때의 결론 / raw
- 불러오기는 두 탭을 합쳐 가져와 페이지에서 대표별로 복원한다.
- **사전 설문**(`survey/`)의 응답은 **사전설문** 탭에 한 고객이 한 줄로 쌓인다. 맨 오른쪽 raw 칸이 상담 도구에 넣는 JSON 이다.
  - v2 코드가 배포돼 있는 동안에는 **기타** 탭에 쌓인다. v3 으로 바꾼 뒤에도 그 응답은 함께 내려받아진다.
  - 응답은 주소만으로는 읽을 수 없고, 받기 페이지(`survey/get.html`)에서 암호를 넣어야 내려받는다.

## 코드 교체 방법 (1분)
1. 시트 → 확장 프로그램 → Apps Script
2. 기존 코드 전부 지우고 `Code.gs` 붙여넣기
3. 맨 위 `const SURVEY_KEY = '';` 의 따옴표 안에 **받기 암호**를 적는다 (길게. 이 암호는 깃에 올리지 않는다) → 저장
4. 배포 → **배포 관리** → 연필 → 버전 **새 버전** → 액세스 **모든 사용자** → 배포
5. 웹 앱 URL은 그대로라 페이지는 안 고쳐도 됨

암호를 비워 두면 응답은 쌓이기만 하고 받기 페이지에서는 내려받을 수 없다. 그때는 시트에서 raw 칸을 복사해 상담 도구에 붙여 넣으면 된다.

예전 '기록' 탭은 테스트 데이터라 지워도 된다.
