# 시트 연결 방법 (2분)

1. https://sheets.new 에서 새 시트 생성, 이름은 "리후 가설검증 기록"
2. 메뉴 확장 프로그램 → Apps Script → 기본 코드 지우고 `Code.gs` 내용 붙이기 → 저장(디스크 아이콘)
3. 오른쪽 위 **배포 → 새 배포** → 톱니에서 유형 **웹 앱** 선택
   - 설명: 리후 기록
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
4. 배포 → 권한 승인(내 계정 선택 → 고급 → 이동 → 허용) → **웹 앱 URL** 복사 (`https://script.google.com/macros/s/.../exec`)
5. 그 URL을 전달하면 `validate.html`의 `SHEET_URL`에 넣어 배포함

이후 효인이 '시트에 저장'을 누르면 '기록' 탭에 가설 10행이 시각·기록자와 함께 쌓인다.
